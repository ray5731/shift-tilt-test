# Shift tilt test

Test pages for the Shift stained-glass puzzle: the glass drawn in 3D on the graphics chip, with a view that follows the phone's tilt.

- 3dplus.html: 3D glass with taller lead and brighter edges
- 3d.html: 3D glass
- tilt.html: the first test (flat tiles, moving sky)

On an iPhone, tap once and allow motion access when asked.
